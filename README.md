# Project 12: Color_Cards.com
Color Cards is a web-based design project developed during my first year in Web Development. It showcases a collection of carefully selected color palettes, each paired with descriptive meanings to highlight their emotional and visual impact.

The project focuses on creating a clean and responsive user interface using HTML and CSS, emphasizing layout design, typography, and visual hierarchy. It also demonstrates my ability to design aesthetically pleasing components such as cards, grids, and interactive elements.

Through this project, I explored how colors influence user perception and how thoughtful design can enhance user experience. This serves as a foundation for my future projects, including my platform Pinspire, where visual inspiration plays a key role.
